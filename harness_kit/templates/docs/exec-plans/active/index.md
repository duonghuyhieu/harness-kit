# Active plans

Each active execution plan is one file in this directory, named `YYYY-MM-DD-topic.md`.
A plan is needed when work spans multiple sessions, touches several subsystems, or has open decisions.

Minimum sections: goal · scope / out of scope · how to verify · risks · progress log · open decisions.
When done, move it to `../completed/` (don't delete — it is the repo's memory).
